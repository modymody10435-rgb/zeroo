# نظام إدارة مخزن المعمل — Streamlit + PostgreSQL

هذه النسخة مخصصة لتشغيل واجهة Streamlit الحالية `app.py` مع PostgreSQL. تم حذف ملفات النسخة المكتبية وواجهة HTML/FastAPI البديلة وملفات البناء والاختبارات غير اللازمة للتشغيل.

## الملفات الأساسية

- `app.py`: واجهة Streamlit الحالية.
- `core/` و`views/`: منطق التطبيق والصفحات والخدمات.
- `requirements.txt`: مكتبات التشغيل.
- `Dockerfile.streamlit` و`docker-compose.streamlit.yml`: تشغيل التطبيق وPostgreSQL.
- `data/مخزن المعمل.xlsx`: البيانات القديمة المستوردة من Google Sheets.
- `scripts/`: تجهيز PostgreSQL واستيراد البيانات أول مرة.
- `data/postgres-data/`: يُنشأ تلقائيًا لتخزين ملفات قاعدة البيانات داخل فولدر المشروع.

## التشغيل على السيرفر

1. ثبّت Docker وDocker Compose على السيرفر.
2. انسخ `.env.example` إلى `.env`، وحدّث `POSTGRES_PASSWORD` بكلمة مرور قوية.
3. من داخل مجلد المشروع شغّل:

```bash
docker compose -f docker-compose.streamlit.yml up -d --build
```

4. افتح `http://SERVER_IP:8501`.
5. راجع السجلات للتأكد من اكتمال استيراد البيانات:

```bash
docker compose -f docker-compose.streamlit.yml logs -f streamlit
```

## استيراد البيانات القديمة

عند أول تشغيل، يحاول `scripts/bootstrap_postgres.py` استيراد ملف Excel إلى PostgreSQL إذا كان جدول `app_sheet_rows` فارغًا. إذا كانت قاعدة البيانات تحتوي بيانات، يتم تخطي الاستيراد لتجنب التكرار أو الكتابة فوق البيانات. ملف Excel محفوظ داخل `data/` ولا تحتاج لإعادة إدخال الأصناف يدويًا.

## تنبيهات مهمة

- لا تحذف `data/postgres-data/`؛ فهو يحتوي قاعدة البيانات الفعلية.
- احتفظ بملف Excel حتى تتأكد من نجاح الاستيراد ومطابقة أعداد السجلات.
- غيّر كلمات المرور الافتراضية قبل إتاحة الموقع للمستخدمين.
- بيانات المستخدمين في ملف Excel تُنقل كما هي، لكن استمرار تسجيل الدخول يعتمد على توافق طريقة التحقق من كلمات المرور في التطبيق.
- تم تجهيز الملفات للنشر، لكن يجب اختبار اتصال PostgreSQL الفعلي بعد تشغيلها على السيرفر.
